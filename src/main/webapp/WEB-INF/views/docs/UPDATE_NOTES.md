# 업데이트 내용 정리

## 1) 지도 페이지 네비게이션 글씨가 안 보이던 문제

지도 페이지에서는 헤더가 투명 상태로 유지되면서, 링크 색상이 흰색으로 고정되어 지도 배경 위에서 글씨가 묻어 보였어요.
`maps.jsp`의 헤더에 `is-solid` 클래스를 적용해서 배경을 solid 처리하고 글씨가 항상 보이도록 맞췄어요.

## 2) 고객센터에서 문의하기 누르면 화면이 바뀌던 문제

고객센터에서 비로그인 상태로 `문의하기/문의 작성`을 누르면 로그인 페이지로 이동해서, 커뮤니티처럼 "현재 화면 유지 + 로그인 모달" 흐름이 끊겼어요.
`support.jsp`에서 링크를 로그인 페이지로 보내는 대신, 실제 문의 URL(`/support/qna`, `/support/qna/new`)로 연결해두고,
비로그인일 때는 기존 `auth-guard.js`가 클릭을 가로채서 로그인 모달을 띄운 뒤 로그인 성공 시 해당 화면으로 이동하도록 흐름을 맞췄어요.

## 3) 관리자 화면에 다크/라이트 테마 적용

관리자 JSP들에 테마용 스타일을 공통으로 적용하려고 `admin-theme.css`를 추가했어요.
각 관리자 페이지에 `admin-theme.css`를 포함했고, `body`에 `admin-page` 클래스를 넣어서 관리자 화면에서만 스타일이 적용되게 했어요.
또 대부분 페이지에 테마 토글 버튼도 같이 넣어두었고, 회원관리 화면의 검색 버튼처럼 색이 겹쳐 보이던 요소들도 테마 기준으로 다시 잡았어요.

## 4) 로그인 실패 문구 변경

로그인 실패 시 표시되던 "아이디가 틀렸습니다." 문구를
"존재 하지 않는 아이디 입니다." 로 변경했어요.
변경 위치는 `auth-modal.js`의 로그인 응답 처리 부분이에요.
